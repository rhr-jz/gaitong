## 2. 我们研究什么？

- **数据**：UCI [Beijing Multi-Site Air Quality](https://archive.ics.uci.edu/dataset/501/beijing+multi+site+air+quality+data)，北京 **12** 个监测站，**2013-03-01 至 2017-02-28**，小时级；主分析聚合为 **站点–日** 日均 PM2.5（见 `src/config.py`）。
- **定位**：以 **统计推断** 为主线（分布 → 区间/检验 → 回归 → 拓展），不是「预测比赛」。
- **现实意义**：PM2.5 关系公众健康与污染治理；2013–2017 恰是北京大气污染治理推进期，便于在讨论中联系政策背景（表述时仍须区分**相关与因果**）。

## 3. 讲义章节 ↔ 本课题（核心对照表）

课程讲义分 **概率论（第 1–5 章）** 与 **数理统计（第 6–10 章）**。本课题主要落在 **第 3–4 章 + 第 6–10 章**；第 1–2 章、第 5 章在拓展部分少量呼应。

| 讲义章节 | 课内知识点 | 在本课题中的用法 |
|----------|------------|------------------|
| **第 3 章** 连续型随机变量 | 密度、分布函数、偏态与重尾 | 描述 PM2.5 的分布；说明为何不宜直接假定正态；对 **log(PM2.5+1)** 做 QQ 图等 |
| **第 4.2 节** 协方差与相关系数 | Pearson / Spearman 相关 | 分析 PM2.5 与温度、风速、降水等气象变量的线性/单调关联 |
| **第 6 章** 数理统计基本概念 | 总体、样本、统计量；χ²、t、F 分布 | 明确「样本」= 站点–日观测；构造样本均值、方差等；为区间估计与检验铺垫 |
| **第 8 章** 区间估计 | 置信区间 | 估计全市（或分季节、分城区/郊区）日均 PM2.5 均值的置信区间 |
| **第 9 章** 假设检验 | 单样本/两样本检验、方差分析 | 检验 **季节间** PM2.5 是否有显著差异（ANOVA + 非参数对照）；检验 **城区 vs 郊区** 站点组差异（Welch t 检验等） |
| **第 9.5 节** 非参数检验 | Kruskal-Wallis 等 | PM2.5 右偏时，作为参数检验的**稳健性补充**（报告里应同时呈现） |
| **第 10 章** 一元/简单线性回归 | 回归模型、显著性、残差 | **多元线性回归**：以 log(PM2.5+1) 为因变量，气象变量 + 季节/站点虚拟变量为自变量；残差诊断 |
| **第 5 章**（拓展）大数定律、CLT | 样本均值近似、重抽样思想 | **Bootstrap** 置信区间；可选小型仿真比较 t 检验在偏态数据下的表现 |

**写报告时的建议**：在「方法介绍」一节用一张小表列出「第 X 章 → 本文用法」，评阅人可一眼看出这是**概率统计课**作业，而非纯 Python 画图作业。

## 4. 四个研究问题与课程方法的对应

| 编号 | 研究问题 | 主要用到的方法 | 建议负责方向 |
|------|----------|----------------|--------------|
| **Q1** | 日均 PM2.5 分布形态如何？能否用正态模型？ | 直方图、QQ 图、描述统计（均值、分位数、偏度） | B：EDA |
| **Q2** | 季节、城区/郊区之间浓度是否有显著差异？ | 置信区间；ANOVA + Kruskal-Wallis；城区/郊区 Welch t 检验 | C：推断 |
| **Q3** | 气象因素与 PM2.5 如何关联？ | 相关分析；多元线性回归 + 残差诊断 | C：回归 |
| **Q4**（拓展） | 重污染日概率是否随季节/区域变化？ | 比例估计、Wilson 区间；可选 logistic 回归 | C + D |
| **拓展** | 偏态数据下传统区间是否可靠？ | Bootstrap 区间；可选 Monte Carlo 仿真 | C |

正文 4–6 页中，**Q1–Q3 占主体**；Q4 与 Bootstrap 占约 0.5–1 页即可。

## 6. 三条必须统一的「统计规范」

1. **分析单位**：主分析用 **站点–日** 日均数据，不用小时数据直接做 t 检验（小时强相关，会夸大显著性）。
2. **变换**：推断与回归优先使用 **log(PM2.5+1)**；正文说明原始浓度右偏、重尾。
3. **表述**：相关与回归只说明**关联**，不写「风速导致 PM2.5 下降」式因果句；局限中写明站点非随机布设、时间自相关等。
